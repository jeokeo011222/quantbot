# 做了个 A 股回测引擎后，我再也不敢相信漂亮的资金曲线

我第一版回测引擎跑出来的曲线，漂亮得不像话。

然后我一个一个往里加约束：加完"次日开盘撮合"，收益掉一截；加完"市场冲击成本"，又掉一截；加完"跌停卖不掉"，再掉一截。

后来想明白了——**那些掉下去的部分，本来就不属于我。**

下面这三个漏斗，每一个都让你的资金曲线变漂亮，而且**默认状态下，全都是开着的**。

---

## 一、前视偏差：最致命的"一天"

最朴素的实现：收盘后跑策略，MACD 金叉了，就以**今天的收盘价**买入。

问题是：今天收盘那一刻，你不可能用今天的收盘价成交。你最早只能在**明天开盘**成交。

只差一天，但这"一天"里藏着整个策略的 alpha。很多策略的收益，就是靠这种错位凭空造出来的。

我把成交时点做成了显式参数：

```go
// ExecSameClose 信号当日收盘价成交（默认，回测偏乐观）
// ExecNextOpen  信号次日开盘价成交（更贴近实际）
```

注意那行注释——**"（默认，回测偏乐观）"**，是我特意写上去的。绝大多数回测框架默认就是这个乐观口径，而使用者根本不知道自己看到的是被美化的数字。**至少在他选择它的时候，代码该诚实告诉他：你在选择乐观。**

前视还藏在更隐蔽的地方：成本模型要用的日波动率 σ，若用含当天的窗口估计，等于用当天价格算当天成本。我们只用 `[0, i-1]` 已收盘数据，多一天都不行。

---

## 二、市场冲击：不出现在交割单上的成本

大部分人算成本，只算"佣金万三 + 印花税"。

但真实成本里还有一个**不出现在任何账单上、却真实吞噬收益的东西——市场冲击成本**。你下单的那一刻，是你在推动价格。

我们的模型对标 cvxportfolio：

```
cost = a·|x| + b·σ·|x|^1.5 / √V + c·x
```

前两项是佣金印花税与市场冲击（Almgren-Chriss 冲击律）。

**请注意那个 `|x|^1.5`。** 它意味着成本随规模**超线性**增长：成交额翻一倍，冲击成本涨近 **3 倍**（2^1.5 ≈ 2.83），而不是 2 倍。

这一个指数，直接决定策略**能不能上规模**——一个在 10 万上夏普 1.5 的策略，放到 1000 万可能连 0.5 都不到。不是策略失效，是你自己的买单把价格推上去了。只算佣金的成本模型，永远看不到这件事。

> **不算市场冲击成本的回测，本质上是在给高换手策略发补贴。**

## 三、参数过拟合：用未来数据拟合参数

"我把 RSI 周期从 14 调到 11，夏普从 0.5 涨到 1.8！"

但如果你用全部历史数据选出最优参数，再报告它在全历史数据上的表现——**你是在用未来数据拟合参数。这不是回测，是作弊。**

我们的网格扫描强制 walk-forward：**前 70% 选参，后 30% 验证**，报告绩效用的是参数没见过、但紧随其后的那 30%。另加两道防线：**至少 1 笔成交兜底**、**组合数上限 200**。

一个诚实的观察：**样本外几乎总是比样本内差。** 如果一样好，八成是你写错了。

---

## 四、A 股特有的坎：跌停卖不掉

涨跌停不用多说：主板 ±10%，创业板/科创板 ±20%。少了它，回测会在涨停板反复买入、在跌停板从容止损——真实市场里**都做不到**。

更致命的是止损约束：

```go
// 成交当日停牌 或 低开/触及跌停封死时无法卖出，保留持仓等待下一根K线。
```

**"跌停卖不掉"这五个字，是 A 股回测与美股回测最大的区别之一。**

它致命在于——**你最想卖的那天，往往恰好就是跌停封死那天。** 所以不考虑它的回测，最大回撤是被**系统性低估**的：止损在最需要它的时候失效了，而模型假装它照常执行。

## 五、真实数据：换个维度，排名就天翻地覆

13 个策略同数据、同规则、同成本模型回测，综合分 `= 0.4×收益% + 0.3×夏普 + 0.3×胜率%`：

| 策略 | 总收益% | 最大回撤% | 换手率 | 综合分 |
|------|--------:|----------:|-------:|-------:|
| RSI超买超卖 | 48.27 | 18.24 | 3.18 | 37.03（第1） |
| 双均线交叉 | 22.88 | 10.19 | 5.43 | 18.89（第7） |
| MTM动量 | 10.39 | 16.71 | **14.66** | 13.93（第10） |
| CCI区间突破 | -7.44 | **28.81** | 9.91 | 6.50（第13） |

换成**收益/回撤比**，结论完全不同：双均线综合分只排第 7，但收益/回撤比 **2.25 全表第二**——22.88% 收益只冒 10.19% 回撤。而布林带突破拿 23.24% 回撤去博 3.30% 收益，风险收益比根本不成立。

> **任何一个单一维度的排名都可以被操纵，包括你自己写的那个公式。**

另：有策略胜率显示 100%，那是**回测区间偏短、成交笔数太少**，不是百发百中。区间必须长到能产生足够样本，指标才有统计意义。

## 六、还没做好的部分

**一个不敢公开缺陷的回测引擎，不值得信任。** 已知未修复的：

- **止损残余前视偏差**：按次日开盘价成交，但当日权益已被提前更新
- **初始资金被悄悄抬高**：输入 10 万可能用更高资金回测，标的间不可比
- **ML 数据泄漏**：用测试集做 early stopping，且用随机 K 折（时间序列上都错）
- **幸存者偏差**：历史池未保留退市股票，样本天然偏乐观

## 七、关于这个项目

这些代码来自 **QuantBot**，我一个人从零写的 A 股量化系统：**Go + React + DuckDB + LLM** 本地桌面应用，自写源码约 **13 万行**，17 种策略 + 5 个 AI Agent 协作。

一条原则从没让步：**LLM 负责理解与决策协作，量化引擎负责计算事实。** 风控门 `生效仓位 = min(规则, 主张, 异议, Kelly)`——**AI 只能让仓位更保守，绝不越线放大。**
