# 同花顺官方金融数据服务接入文档

> QuantBot 通过 `internal/thssdk` 接入同花顺官方金融数据服务（fuyao.aicubes.cn）。该服务为配套 A 股数据 API（`github.com/HiThink-Tech/Financial-API`），提供特色数据、财务三表、估值快照、集合竞价快照、全市场复权因子导出等官方能力。接入遵循「官方真实数据、未配置即报错、严禁伪造」原则。

---

## 1. 概述

同花顺官方数据源是一个**独立于行情数据源选择**的可选付费数据源。启用后可为以下能力供数：

| 能力 | 说明 |
| --- | --- |
| 六维判势情绪面 | 真实涨停/跌停/炸板池 + 连板天梯，得到真实炸板率与最高连板高度 |
| 财务数据同步源切换 | 官方利润表/资产负债表/现金流量表，替代东财/通达信源（无频控） |
| 全市场复权因子导入 | 官方复权事件 Parquet，重建 `stock.adj_event` / `stock.adj_factor` 与 `stock.ohlc_qfq` 前复权视图 |
| 估值快照 | 批量 PE-TTM / PE-MRQ / PB / PS / PCF |
| 集合竞价快照 | 收盘竞价与盘中竞价（匹配量/价、未匹配量） |

所有数据均为官方返回的真实数据；未配置 API Key 时接口统一返回明确的错误提示，不做任何降级伪造。

---

## 2. 配置

配置项在「设置-数据源」页面的**独立卡片**（位于腾讯财经说明区下方），与行情数据源选择完全解耦。持久化于 `config/config.json` 的 `ths_source` 节：

```json
"ths_source": {
  "enabled": false,
  "api_key": "",
  "base_url": ""
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | bool | 是否启用官方数据源 |
| `api_key` | string | 官方 API Key（X-api-key），明文存储，与其他 Key 一致 |
| `base_url` | string | 服务地址，留空使用官方默认 `https://fuyao.aicubes.cn` |

### 后端方法

- `GetTHSConfig() -> THSConfig`：读取配置。
- `SetTHSConfig(enabled, apiKey, baseURL)`：保存配置并**立即重建**包级 `thssdk` 客户端，无需重启。未启用或 Key 为空则禁用官方源；仅在启用但 Key 为空时报错拦截。

配置文件迁移逻辑见 `internal/config/config.go` `load()`，旧配置无 `ths_source` 时默认关闭，不引入额外网络依赖。

## 3. 包结构

```
internal/thssdk/
├── ths.go       # Client，统一 X-api-key 认证 + 限流；各数据获取方法
├── client.go    # 包级默认客户端（Configure 注入）、TTL 缓存、组合接口
└── data.go      # API 响应结构体定义（可空数值用 *float64）
```

关键机制：

- **包级默认客户端**：`thssdk.Configure(apiKey, baseURL)` 由 App 启动/保存配置时注入；`thssdk.Default()` 取用。未 Config 时返回 `nil`，业务侧据此报错。
- **节流限流**：`throttle` 保证最小请求间隔，避免撞官方额度。
- **TTL 缓存**：跨模块共享的数据（如情绪面快照）带有效期缓存。

## 4. 功能接入点

### 4.1 六维判势情绪源升级（internal/sixdim/fetcher.go）

六维判势的「情绪赚钱效应」维度按可配置优先级取数，首个成功源生效，高优先级失败自动回退：

```
同花顺官方(ths_boards) → 东财 push2ex 实时涨停池(limit_board) → DuckDB 全市场统计(full_market_stats) → 采样日线代理(sample)
```

- `fillSentiment` 尝试 `cachedTHSSentiment`（`thssdk.FetchSentimentSnapshot`），取涨停数/跌停数/炸板数/连板高度，计算真实炸板率。
- 数据带 5 分钟 TTL 缓存 + 外部请求节流（`throttleExternal`）与来源埋点（`recordSourceStat`）。
- 数据源开关与优先级在「设置-数据源」的六维源卡片中配置（`ths_boards`），未配置官方 Key 时该源失败自动回退东财，全程无伪造。

### 4.2 财务同步源切换（App.StartFinancialSync）

`StartFinancialSync(mode, source)` 的 `source` 支持：

- `em`：东方财富 datacenter（默认）
- `tdx`：通达信终端（需主程序登录并已下载专业财务数据）
- `ths`：同花顺官方（需启用并填 Key，否则直接拒绝）

同花顺路径注入 `data.NewTHSFinancialFetcher()`，实现 `FinancialFetcher` 接口：拉取利润表/资产负债表/现金流量表，按报告期对齐计算毛利率/净利率/ROE/资产负债率/营收与净利同比，支持截断增量。

### 4.3 复权因子导入（DuckDBManager.ImportTHSAdjFactors）

1. 通过 `thssdk.DumpDownloadURL` 获取复权事件 Parquet 预签名地址（约 5 分钟有效期），立即下载到本地。
2. 重建 `stock.adj_event`（清空后从 Parquet 全量导入，thscode → 小写前缀 symbol）。
3. 推算日频复权因子到 `stock.adj_factor`（官方算法：单除权比例 → 累计连乘 backward → 归一化 forward）。
4. 刷新 `stock.ohlc_qfq` 前复权视图。

查询入口：`GetAdjustedKline(symbol, limit)`（支持纯代码/带前缀）。状态入口：`GetTHSAdjFactorStatus()`。

### 4.4 估值与集合竞价快照（app_ths.go）

- `parseTHSCodes(raw)`：纯代码按首位规则判断交易所（6xx→SH、0xx/3xx→SZ、8xx/43x/92x→BJ），**避免 000001 被误判为沪市**；最多 100 个。
- `GetTHSValuationSnapshot(codes)`：批量估值快照（PE/PB/PS/PCF）。
- `GetTHSAuctionSnapshot(codes, stage)`：集合竞价快照（`final` 收盘竞价 / `live` 盘中竞价），返回竞价阶段、数据状态与逐项竞价价/量/未匹配量。

## 5. 前端（ui/src/pages/Settings.tsx）

- 独立卡片：「同花顺官方金融数据服务（fuyao.aicubes.cn）」，含启用开关、API Key（密码框）、服务地址（默认占位）与「保存」按钮；展开态高亮 + 「展开/收起」提示。
- 六维数据源配置新增 `ths_boards` 项（启用开关 + 优先级），描述「官方涨停/跌停/炸板池+连板天梯，需启用上方官方源并填 Key」。
- 数据维护区：
  - 财务数据维护：数据源下拉新增「同花顺官方（真实报表，无频控，需配置 API Key）」。
  - 复权因子导入 + 前复权查询卡片：一键导入全市场复权因子、查看状态、按代码查前复权 K 线。
  - 估值/集合竞价快照查询卡片：输入代码列表，查询估值或集合竞价快照并渲染结果表。

## 6. 自查清单

接入完成后建议逐项核对：

- [ ] `go build ./...` 通过；`npm run build`（tsc + vite）通过。
- [ ] Wails 绑定已生成：`SetTHSConfig`/`GetTHSConfig`/`ImportTHSAdjFactors`/`GetTHSAdjFactorStatus`/`GetTHSValuationSnapshot`/`GetTHSAuctionSnapshot`/`GetAdjustedKline`/`StartFinancialSync`。
- [ ] 配置保存后立即生效，无需重启（`SetTHSConfig` 重建包级客户端）。
- [ ] 未配置 Key 时：六维回退到东财/push2ex/DuckDB，财务同步与快照接口报错而非伪造。
- [ ] 旧配置迁移：无 `sixdim_source` 时整体用默认；有 `sixdim_source` 但缺 `ths_boards` 时补默认（`needSixDimTHSDefault`）。
- [ ] 复权因子上限：官方 Parquet 导入、日频因子推算、前复权视图三级清晰。
