# QuantBot 用户手册

> QuantBot（AI 量化机器人）是一款由大模型驱动的 A 股智能量化机器人。系统采用多 Agent 协作架构（Planner、Quant、CIO、Risk、Trader 五大智能体），覆盖盘前分析、盘中监控、盘后复盘全流程。

- **程序文件**：`QuantBot.exe`
- **技术栈**：Go + React + SQLite + DuckDB
- **适用市场**：中国 A 股（沪深股市）
- **文档版本**：V1.6.0　**更新日期**：2026-09-18

**快速上手三步走**：① 下载 → ② 配置（AI + 数据维护）→ ③ 运行投资规划 & 模拟交易。详见下文各章节。

将整个压缩包解压到本地硬盘，确保目录结构完整，至少包含：

- `QuantBot.exe` —— 主程序
- `config\config.json` —— 配置文件
- `data\stock_dict.json` —— 股票代码/名称字典（**必需**，缺失将导致无法解析股票）

- `data\quantpilot.duckdb`、`data\stock.duckdb` —— DuckDB 股票时序数据库
- `database\quantpilot.db` —— SQLite 数据库（投资组合、交易、决策等）
- `models\` —— 机器学习模型文件（XGBoost / LightGBM / 随机森林 / 逻辑回归 / MLP 及标准化参数）

### 1.4 启动与首次配置

1. 双击 `QuantBot.exe` 启动。首次启动会自动初始化数据库并进入「**欢迎向导**」。
2. 向导中设置：

3. 进入主界面后，请先按**第 2 章**完成关键配置再开始使用。

## 2. 参数配置

所有配置均在左侧菜单「**设置**」页中完成。**本节是全系统最重要、最影响运行结果的配置入口**，其中「AI」与「数据维护」两项务必重点配置。

### 2.1 AI 配置（重点）

系统依赖大模型进行决策推理，**AI 配置是否有效决定了全系统能否正常运行**。

| 参数 | 说明 |
| ---- | ---- |
| AI 提供商 | DeepSeek / 豆包 / 千问 / Other |
| 模型 | 模型名称，如 `deepseek-Flash` |
| 接口地址 | 兼容 OpenAI 格式的 Base URL |
| API Key | 你的模型服务密钥（密码形式输入，仅保存在本地 `config\config.json`） |
| 测试连接 | 验证模型可用性，返回模型名、响应时间与回复内容 |

> **务必**：保存后点击「**测试连接**」验证 Key 有效。系统健康检测中的 AI 服务状态、智能体分析与每日决策都依赖此处 Key 的有效性。

### 2.2 数据维护与股票数据更新（重点）

选股、回测、风险分析使用本地 DuckDB 行情数据。**请每日更新 K 线数据，保持股票数据最新**，否则当日行情无法参与选股与回测。

> **每日更新步骤（务必在交易日收盘后执行）：**
>
> 1. 先**打开通达信金融终端，下载当日完整的日线（`.day`）数据**（确保覆盖全市场所有股票）。
> 2. 再回到 QuantBot →「设置 → **数据维护**」→ 在「TDX 数据路径」填入通达信安装目录。
> 3. 点击「**开始同步**」：系统会从通达信 `vipdoc` 文件夹的 `.day` 日线文件同步历史行情到 `stock.duckdb`，并重建 ohlc 行情表。
> 4. 同步期间**请勿关闭程序**；数据量较大时耗时较长属正常。建议在交易日收盘后养成每日同步的习惯，保证次日盘前选股、回测数据最新、最准确。
>
> 除通达信外，还可使用**同花顺官方金融数据**：「设置 → 数据维护 → 同花顺」提供数据同步能力——**一键同步全部（复权因子 + 交易日历）**、仅导入复权因子、财务三表同步、全市场日K导入（近3年）。复权因子用于构建前复权行情视图供回测/选股使用；交易日历数据来自同花顺官方近一年交易日序列。未配置官方 API Key 时同步请求将被拒绝（严禁伪造数据）。

### 2.4 交易模式（由「通用 → 启用弹窗」控制）

> 自 v1.5.0 起，「交易接口」设置页已移除，实盘/模拟模式统一由**通用页签的「启用弹窗」开关**决定：

- **启用弹窗（模拟交易，默认）**：使用内置模拟撮合，不涉及真实资金，用于学习和验证策略。模拟模式下智能体发出的交易指令需**人工弹窗确认**（见 3.3）。
- **关闭弹窗（实盘交易）**：系统不内置具体券商连接，提供**开放的实盘接口框架**。实盘下单需自行对接券商（如基于迅投 QMT / XtQuant 编写对接程序并配置注册），并保证对接环境就绪。**切换实盘前请务必阅读风险提示，并在模拟模式下充分验证策略。**

### 2.5 数据源

「设置 → 数据源」页含**两个相互独立**的子页签：**行情数据**（实时行情数据源选择）与**市场信息数据**（市场六维判势 / 同花顺官方数据源），互不影响。

**① 行情数据**（实时行情数据源，任选其一并保存）：

| 数据源 | 说明 |
| ---- | ---- |
| 原生 TDX | 内置 Go 原生通达信客户端，需先点击「连接」 |
| TDX MCP | 通过 MCP 服务读取通达信数据 |
| MCP | 通用 MCP 数据服务 |
| 通达信终端接口 | 需通达信主程序 `TdxW.exe` 已启动并登录 |
| 腾讯财经 | **无需安装任何软件**，直接读取腾讯财经实时行情，推荐无通达信环境的用户 |

- 数据源仅影响**实时行情读取**（组合、看板、指数、交易报价等）；研究中心的选股引擎、策略、回测始终使用本地 DuckDB 数据。

**② 市场信息数据**（数据源卡片**并排互斥**，点击展开对应配置）：

- **市场六维判势**：配置六维实时数据源（涨停/跌停/炸板池、连板天梯、北向资金、隔夜外围指数等）。其启用开关与「行情数据」子页签的数据源选择**完全解耦**。展开该卡片后提供两个操作按钮：
  - **数据测试**：绕过缓存逐个探测各数据源连通性（外部源带 6s 超时+限流），返回每源启用状态 / 连通成败 / 耗时 / 失败原因，帮助判断高优先级源健康度。
  - **后台强制刷新**：穿透缓存重新执行一次市场六维判势并落库至 `market_sixdim_daily`，同时清空报告短缓存，前端「市场六维判势」卡片立即显示最新结果。
- **同花顺官方**：填写官方 API Key 后用于涨停/跌停/炸板池、财务报表、复权因子、交易日历等数据，数据全部官方真实、严禁伪造（详见《同花顺官方数据源接入.md》）。

- **财务/公告数据源**：默认**通达信终端**（本地 RPC，不封 IP），也可切换到**同花顺官方**（需 API Key）或东方财富；公告数据在巨潮资讯不可用时自动回退到东方财富（单源 6 秒超时）。
- 切换数据源后需「保存」并**重启程序后生效**。

### 3.1 界面总览

左侧菜单栏按功能分组，主要页面包括：

| 投资规划 | 基于资金规模的组合规划（见 3.2） |
| 投资管理 | 投资规划与执行、每日决策、每日复盘 |

### 3.2 投资规划（重点）

投资规划是系统的**起点**，先基于你的资金规模与风险偏好确定「买什么、买多少」。

1. 进入「**投资规划**」页，完成投资者画像（投资经验、风险承受能力等）。画像中新增一道口语化选择题「**行情走弱时会怎么反应？**」（例如：先拿着别慌／趁机捡点防御龙头／先减仓躲一躲／照常按计划走），你的回答会**轻微影响最终的风险等级**。
2. 系统据此生成投资方案（含候选策略与目标收益/回撤），选择方案后即可**生成投资计划与股票池**。
3. 投资计划进入 ACTIVE/RUNNING 状态后，系统会在每个交易日按计划自动进行盘前决策、盘中监控与盘后复盘。

> **目标权重**：投资方案的目标权重中，单票上限按风险等级取 **保守 15%／均衡 20%／成长 30%**。对于小额「**成长型 + 本金 < 50 万**」的方案，系统采用**激进配置**——即使行情偏弱也至少保留 **3 只候选股票**、现金约 **10%**，避免资金闲置。

> 提示：投资规划决定了系统后续自动交易的范围与额度，请先完成规划，再启动连续交易或让智能体贴合执行。

### 3.3 模拟交易与弹窗确认（重点）

在**模拟接口模式**下，智能体（CIO/Trader）生成的每一笔交易指令，都需要**人工弹窗确认**后才能成交。

- 当智能体计划下单时，屏幕中央会弹出「**智能体交易确认**」窗口，展示：
  - **交易方向**（买入/卖出）、**股票**（名称与代码）、**数量**、**价格**、**交易金额**；
  - **交易原因**（为什么下单）与**决策 ID**（可追溯）。
- 核对无误后点击「**确认买入 / 确认卖出**」放行成交；若不认可可点击「**拒绝**」拦下该笔交易。
- 未及时确认的交易会**保持排队等待**，可稍后确认或拒绝；到了日终结算，仍未确认的排队交易会被判定失败并自动移出队列。
- 成交事件会同时展示**股票代码与名称**，不同股票即使名称相似（如「中兴通讯」与「中兴商业」）也不会显示混淆。

> 这是模拟模式下系统的默认安全机制——**所有自动化交易在你确认前不会真正成交**。请养成“先看弹窗、再点确认”的习惯，既能验证策略，又能避免误交易。

### 3.4 每日运行流程

系统按 A 股交易时段自动调度：

1. **盘前（9:15–9:30）**：生成当日 AI 决策（Planner → Quant → Risk → CIO 决策链）。CIO 会先执行**市场六维判势**（技术/广度/量能/资金/情绪/外部 六维实时评分），据此得到**仓位系数**并缩放买入信号（卖出不受影响）；随后进入**决策主张层**：LLM 基于真实证据链提出主张、经质疑者**对抗评审**，再组织**多空辩论**（同时摆出看多/看空论据并给出共识度），以「主张置信度 × 多空共识度」计算 **Kelly 仓位缩放**，再做**多提案集成投票**（汇总主张/异议/辩论/规则的方向形成多数方向校验）——共识或信心不足时进一步下调买入仓位，且只更保守、绝不放大而越过规则风控门；同时读取「今日交易策略」，若策略信号为卖出（如 KDJ 死叉）则生成清仓卖单，且**优先于市场状态机**执行。
2. **盘中（9:30–11:30、13:00–15:00）**：每 10 分钟监控 ACTIVE/RUNNING 投资方案，复用六维判势；若仓位系数过低（<0.2）或判为「退潮风险」则告警并转观望。操盘手按「今日交易策略」信号执行减仓（策略卖出信号优先）。
3. **盘后（15:00 后）**：当日结算（记录总资产、今日盈亏等）、量化因子复盘（15:15，产出各因子质量分并持久化）、策略参数调优（15:05）、CIO 深度复盘与制定明日计划（15:15）；盘后自动/量化分析师为**下一交易日选定交易策略**写入「今日交易策略」。
4. **连续监控**：每日收盘后自动采集股票池**盘口摘要**落库，供次日的盘口因子选股评分使用。

> **市场六维判势（MarketSixDim）**：六维权重为 技术0.15 / 广度0.20 / 量能0.15 / 资金0.15 / 情绪0.25 / 外部0.10。评分经冲突修正后映射到仓位系数——≥80 强势（0.8~1.0）、60~79 结构性震荡（0.4~0.6）、40~59 偏弱（0.2~0.3）、<40 退潮风险（0.0~0.1）。
>
> **市场广度口径（真实数据）**：广度维度基于「分层代表样本」（沪/深/创/科创/北交按全市场占比等比例抽样，固定种子可复现，消除旧版字典序截断全落北交所+沪600的偏差），统一计算 涨跌家数/20日新高新低/涨跌停比/主线板块数 四张胞。交易时段内（含盘前竞价）用活跃实时行情源的真实快照覆盖样本最新价/前收/最高，使广度呈现实时口径，且有 30s 批快照缓存去抖；20日新高/新低按「当前价之前的最近20根历史」严格判定（无 off-by-one）。涨跌停比优先用东财 push2ex 实时【全市场】涨停/跌停池，失败回退代表样本。每个成分在判势来源中如实标注数据源与覆盖家数；样本明显不足(<100)会标注低可信度。

> **工作流容错**：每日投资工作流采用「单步失败不中断」策略——盘前、CIO 决策、风控、盘中、盘后各阶段独立执行，某一阶段失败仅记录留痕，其余阶段继续推进；即使盘后主分析周期失败，每日结算、盘口摘要与每日复盘仍会照常执行，避免单点故障中断整条投资链路。

### 3.5 手动操作

- **运行每日分析**：在日报页点击「运行每日分析」手动触发一次完整 AI 决策链。
- **查看决策**：CIO 页或日报页查看当日决策明细（买入/卖出指令、理由、风险审批、待确认交易）。当决策经过了多空辩论时，会在决策证据中展示【多空辩论】——含方向、共识度、看多/看空论据，以及 **Kelly 仓位缩放系数**（<1 时表明已因共识/信心不足而收紧买入仓位）；并展示【多提案集成】——主张/异议/辩论/规则多来源的方向多数校验与净多分。
- **查看市场判势**：CIO 页「**市场六维判势**」卡片展示最近 7 日的六维得分、仓位系数与市场标签；「**今日交易策略**」卡片展示当前/近期生效的交易策略及已执行卖出次数。
- **启动/停止连续交易**：日报页提供「启动/停止」连续交易开关（模拟模式下用于验证自动撮合）。

## 4. 高级应用（研究部分）

研究部分提供专业的量化研究工具，帮助选股、验证策略与监控市场，是进阶使用「研究中心」的全部能力。

### 4.1 选股引擎

多因子智能选股，通过因子加权评分从全市场筛选出高分标的，生成股票池。

- 设置筛选条件（策略模板、因子权重）后点击「开始选股」，系统按 `Score = Σ(权重×因子分)` 综合评分并排序。
- 筛选结果可加入自选、生成目标股票池；专业模式下点击个股可打开详情弹窗，在「**因子评分**」区查看各维度得分，其中 **盘口因子**（量比/内外盘/封板）以琥珀色条展示，权重 5%。
- **因子权重自适应**：系统在盘后因子复盘后，会根据各因子近期质量分自动缩放默认权重（好因子上调、差因子下调），让“当前市场下更有效的因子”权重更高。质量分参考值用**中位数**（对极值更稳健），避免个别突兀噪声扭曲「平均线」。
- **分半稳定性检验**：因子复盘会对每个因子做**分半稳定性检验**——将横截面样本按固定种子随机两分、分别计算两半段 RankIC，只有两半段方向一致且强度达标（|IC|≥0.02）才判为「稳定」；被判定不稳定且**样本量足够（≥30，可真实判定）**的因子被怀疑为假阳性，质量分的 IC 贡献减半、选股权重进一步降权（先封顶再砍半），让历史无效或偶然相关的因子在选股中自然退场；样本不足时视为「无法判定」、不武断下线（其低覆盖率已自然拉低质量分）。
- **盘口因子说明**：数据来自上一交易日收盘落库的 `order_book_daily`，样本不足（<20 只）时该因子整体不参与评分，属正常降级。
- **选股硬筛选**：系统在评分基础上叠加两道硬门槛——① **流动性硬下限**：流动性因子分过低（约低于全市场均值下方 0.5σ）的标的直接剔除；② **流通市值区间**：按「最新收盘价 × 流通股本」计算，剔除流通市值小于 20 亿或大于 200 亿的标的（缺股本资料时按放行处理，不因缺数据误伤）。

### 4.2 策略管理

内置 17 个策略（双均线、EXPMA、布林带、RSI、KDJ、海龟、MFI、MTM、DMI、CCI、TRIX、捉妖大师、机器学习，以及新增的超级趋势、Aroon、HMA、CMF 资金流向），支持查看/新建/启停。

- 每个策略展示类型、启停状态与表现指标（夏普、最大回撤、总收益等）。
- **新增趋势/资金策略**：本次引入 4 个新策略——
  - **超级趋势**：用 ATR 动态画一条跟踪趋势的通道线，自带上/下翻转止损，趋势反转即买卖，特别适合单边行情里拿住趋势并自动防守回撤。
  - **Aroon**：统计近期创新高/新低的时间，判断新一轮趋势是否启动或转弱，用于过滤震荡市的假信号。
  - **HMA（赫尔均线）**：比普通均线更跟手、滞后更小的趋势线，价格上穿买入、下穿卖出。
  - **CMF 资金流向**：衡量一段时间的资金净流入/净流出，资金确认流入才买入、确认流出才卖出，用于过滤量能不配合的假突破。
- **机器学习策略**：基于 5 模型集成（XGBoost、LightGBM、随机森林、逻辑回归、MLP）的 AI 选股策略，默认**概率平均**融合各模型预测，纯 Go 本地推理、无需 Python；模型文件缺失或加载失败时自动回退到多因子本地评分模型。
- 策略指标通过「**样本池回测**」刷新——以真实持仓+基准指数为样本回测后聚合计算，样本量更足，胜率等指标更真实。
- **今日交易策略**：盘后量化分析师为下一交易日选定一个策略（否则系统按回测指标自动选择）；次日盘前/盘中，操盘手按该策略对持仓发出卖出信号（如 KDJ 死叉）时自动减仓，策略卖出信号优先于市场状态机执行。

### 4.3 回测分析

策略历史回测验证：

- 选择标的/指数、回测区间、初始资金与策略，点击「开始回测」。
- 查看年化收益、夏普比率、最大回撤、波动率、胜率、盈亏比等指标与权益曲线。
- 回测使用本地 DuckDB 真实历史 K 线（请先按 2.2 每日更新数据）；遵循 A 股规则（T+1、整手、佣金+印花税）。
- **多策略并行测试**：刷新/批量回测多个策略时，系统只加载一次数据，通过后台并发（最多 8 个 worker）并行跑各策略，显著提升批量测试速度，等待时间大幅缩短。

### 4.4 投资组合中心

基于**真实持仓 + 日 K 协方差**，给出 **MVO（均值-方差优化）、风险平价、风险预算**三种算法下的最优配置。页面标题注明「**仅供研究，不影响投资决策**」。

- 可**手动运行组合优化**，查看算法给出的推荐权重（代码/名称/比例）。
- 以上结果**仅供研究参考**，不会自动改动持仓，也不会触发任何交易。

## 5. 注意事项

### 5.1 交易规则（A 股）

- **T+1**：当日买入的股票当日不能卖出。
- **交易时段**：9:30–11:30、13:00–15:00；周末及法定节假日休市。
- **整手交易**：买入按 100 股整数倍（自动向下取整）。
- **手续费**：买入收佣金（万三，最低 5 元），不收印花税；卖出收佣金 + 印花税（0.05%）。
- **盘口拦截**：买入会拦截**跌停板**及**涨停封死**（挂单排队买不进）标的；卖出会拦截**跌停封死**（当天无法成交）标的，跌停打开时则允许按跌停价立即离场。
- **盘口五态**：系统按 涨停封死/涨停打开/跌停封死/跌停打开/正常 五态判定盘口状态，并识别「巨量跌停」（量比≥2 且触及跌停）与「内盘占比>0.6 抛压」信号。
- **系统风控硬限制**：单票权重上限 **30%**、组合最大回撤容忍 **10%**。
- **执行端买入硬风控**：每笔买入在执行前校验——单票持仓集中度不超上限（默认 30%），且标的近期流动性（近 20 日换手率与名义成交额）需达到阈值，拥挤度过高时拒绝下单，防止买入后跑不掉。
- **CIO 建仓门控**：提供「**暂停建仓**」开关，只拦截买入、放行卖出；当市场六维判势为「**退潮风险**」或**仓位系数 ≤ 0.15** 时，不会生成新的买入（BUY）订单——该门控仅影响新建仓，不影响减仓/止损卖出。
- **股票池白名单**：买入标的须通过股票池白名单，不在可交易池内的标的不会买入。

### 5.2 数据与持仓口径

- **今日盈亏** = 今日总资产 − 昨日总资产；**累计盈亏** = 今日总资产 − 期初资产（期初资产固定为初始资金）。
- **持仓价值**：交易时段内取实时行情，非交易时段取数据库中最近结算收盘价。
- 页面刷新以数据库数据为准；刷新失败时会弹窗提示并每 30 秒自动重试直至成功。
- 组合会自动过滤高价股（单标的预算不足买入 1 手）并纳入低价股 / ETF；不可交易持仓自动剔除并重新分配权重。
- **持仓数量分档**：<3 万 → 4 只；3–10 万 → 5 只；10–30 万 → 8 只；30–100 万 → 12 只；≥100 万 → 15 只。

### 5.3 设置项注意

- **AI API Key**：请妥善保管，密钥仅保存在本地 `config\config.json`。请勿把该文件分享或提交到公开仓库。
- **实盘交易**：实盘模式由「通用 → 启用弹窗」关闭时进入，实盘下单需自行开发/配置券商实盘接口（如基于迅投 QMT / XtQuant 实现），遵循系统实盘接口约定。实盘涉及真实资金，务必先在模拟模式充分验证策略；切换前须确认对接环境就绪。
- **数据源切换**：切换后需点击「保存」并重启程序后生效。若选「通达信终端接口」，须先启动通达信主程序并登录。
- **指数显示**：指数快照使用实时数据，实时数据获取失败时会弹窗报错，而非显示离线数据。
- **初始资金**：修改初始资金会影响后续持仓分档与建仓规模；CIO 执行买入前会校验真实可用资金，超额时按比例削峰。
- **市场状态**：当市场情绪极弱（confidence ≥ 0.97）时，CIO 不执行常规建仓，仅考虑防御性买入。
- **数据维护**：同步 TDX 日线会重建 ohlc 表，同步期间请勿关闭程序；建议每日在通达信金融终端下载完整的日线数据后再同步数据（见 2.2），确保选股与回测数据准确。
- **日志与备份**：`database\quantpilot.db` 包含全部交易与决策记录，建议定期备份。
- **市场六维判势**：六维数据来自本地 DuckDB 真实行情；其中北向资金以「全市场成交额连续放量天数」代理、炸板率以「日线触板未封」代理，隔夜外围与事件风险取中性默认——这些已在判势卡片标注数据来源，避免误读。
- **策略驱动减仓**：盘后量化分析师会为次日选定交易策略（否则系统按回测指标自动选择）。次日盘前/盘中，若该策略对持仓发出卖出信号（如 KDJ 死叉），操盘手会生成清仓卖单，且**优先于市场状态机执行**。若想改用其它策略，可在盘后让量化分析师通过 `select_next_day_strategy` 工具重新指定。
- **多空辩论与 Kelly 缩放**：盘前 CIO 决策会组织多空辩论并计算 Kelly 仓位缩放，再做多提案集成投票（多来源方向校验）。只有当识别到多空一致（共识度高）且主张官信心足时，买入仓位才可能维持较高水平；共识或信心不足时收紧买入仓位。这些机制均只可能让决策**更保守**，绝不会放大买入而突破规则风控门。若未配置 AI，决策会完全回退到规则层（无辩论/集成），不影响系统运行。
- **软件更新**：更新包解压后自动校验（禁止覆盖数据库、配置与日志等用户数据），应用下载完成后重启即完成升级。
